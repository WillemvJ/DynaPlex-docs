Getting help
============

We are happy to discuss issues in the `GitHub repository <https://github.com/WillemvJ/DynaPlex-docs/issues>`_. Please open a new issue if you want to discuss something with us. This includes questions. 

When you find a bug: open a new issue, please include a short, self-contained script that reproduces the problem, and indicate the python version, the DynaPlex version, the platform (Windows, Linux, macOS), and the version of pytorch.
